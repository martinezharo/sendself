SendSelf / How it works

Three simple steps

Move text and files between your own devices.

Create one private space, link the devices you use, and let encrypted messages wait for the device that needs them.

Create a private space

Start on any device without an account, email, or server password. The device creates the local identity and encrypted space used by your linked devices.

Link your devices

Open the pairing flow on a phone, laptop, or tablet and scan the QR code from a device already in the space.

Send without waiting

Send a message or a file up to 50 MiB. Content is encrypted before upload; if the recipient is offline, delivery waits until it reconnects, with undelivered server copies cleaned up within 24 hours.

Keep using it offline

Install the progressive web app to keep local history available and save outgoing messages or selected files locally. Nothing is uploaded or delivered until you reconnect.
