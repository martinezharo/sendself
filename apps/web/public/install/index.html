SendSelf / Install

Installable by design

Keep your private space one tap away.

SendSelf is a progressive web app. Install it from a supported browser on each device you want to use, then pair those devices inside the app.

Desktop browsers

Open the app homepage in a supported browser. Use the install icon in the address bar, or choose the browser's option to install the site as an app.

Mobile browsers

Open the homepage on your phone. Use the browser menu and choose “Add to Home Screen” or its equivalent, then open the new app icon.

After installing

Create a space on the first device. On the next device choose to link to an existing space and complete the QR-code pairing flow.

Offline use

The installed app keeps local history available and can save outgoing messages or selected files locally. Nothing is uploaded or delivered until you reconnect.
